Zenieth – Resume Analyzer & Social Networking App

Zenieth is an innovative social media application that not only helps users create, analyze, and rank resumes but also connects them with friends and professional networks. It combines AI-powered resume analysis with social networking features to help users grow their careers.

Features

Resume Analyzer: Upload your resume and get an AI-powered evaluation with insights for improvement.

Resume Builder: Create professional resumes directly within the app with templates and tips.

Resume Ranking: Compare your resume against others and see how it ranks in different skill categories.

Social Networking: Connect with friends, colleagues, and professionals in your industry.

Activity Feed: Share achievements, updates, and career milestones with your network.

Notifications: Get alerts about resume rankings, friend requests, and professional tips.

Technology Stack

Frontend: React / Vite / Tailwind CSS

Backend: Node.js / Express

Database: MongoDB / Firebase

AI & ML: OpenAI API or Google Gemini API for resume analysis

Authentication: JWT / OAuth

Deployment: Vercel / Netlify

Installation

Clone the repository

git clone https://github.com/yourusername/zenieth.git
cd zenieth


Install dependencies

npm install


Set up environment variables
Create a .env file and add:

API_KEY=your_ai_api_key
DATABASE_URL=your_database_url


Run the application

npm run dev

Usage

Sign up or log in.

Upload your resume or create a new one.

Get AI-powered analysis and ranking.

Connect with friends and explore their resumes.

Improve your resume based on suggestions and climb the ranking.
